# Installation

Clone this repo: LINK
cd docker-watchdog

cp watchdog.sh /usr/bin/watchdog

mkdir /etc/watchdog
chmod 700 /etc/watchdog

cp .env.example /etc/watchdog/.env
chmod 600 /etc/watchdog/.env

mkdir -p /etc/watchdog/states
chmod 700 /etc/watchdog/states
